# MovilBoost
Cliente de FPS para Minecraft 1.21.11 + Fabric, pensado para celular (Zalith/Amethyst/Pojav).
Incluye: Fabric API, Sodium, Sodium Extra, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, ModernFix + ajustes basicos (options.txt).
